# Dynamic Textures

Dynamic Textures 是一个基于 React、Vite、TypeScript、Canvas 和 WebGL 的动态纹理编辑器。它可以在浏览器中制作半调点阵、动态渐变和效果叠加效果，并将当前画布导出为 PNG 图片。

## 快速开始

安装依赖：

```bash
npm install
```

启动开发服务：

```bash
npm run dev
```

默认访问地址为 `http://localhost:3001`。如果端口被占用，Vite 可能会自动切换到其他端口，请以终端输出为准。

## 常用命令

```bash
npm run dev
```

启动本地开发环境，支持预设文件读写。

```bash
npm run build
```

执行 TypeScript 检查并生成生产构建，输出到 `dist/`。

```bash
npm run preview
```

先构建项目，再通过 Wrangler 在本地预览生产环境。

```bash
npm run deploy
```

构建并通过 Wrangler 部署。

## 使用方式

1. 打开页面后，在画布区域查看实时预览。
2. 在画布面板中设置画布宽高和预览背景色。
3. 新增或选择纹理图层，调整半调点阵、渐变、动画、边缘淡出、鼠标交互以及统一的变换参数组（缩放、XY 比例、X/Y 偏移）。
4. 通过图层面板调整可见性、顺序、混合模式，或添加效果层。
5. 使用涂抹扭曲、绘制遮罩等效果时，在预览画布上直接绘制。
6. 将当前效果保存为预设，或从预设列表中切换已有方案。
7. 点击导出按钮，将当前合成结果按画布尺寸下载为 PNG。

## 功能特性

- 半调点阵：支持圆形、方形、菱形、加号、星形和字符点阵，可调点阵间距、大小范围、透明度、阈值、对比度、随机性和扰动。
- 斑纹控制：支持高斯、波浪、蜂窝、涟漪、条纹等斑纹类型，并可调整数量、尺寸、模糊等核心参数。
- 统一变换参数组：图层类型与形变效果共享同一组变换参数（缩放 1-10、XY 比例 0.1-10、X 轴偏移 -W 到 W、Y 轴偏移 -H 到 H），以画布中心为缩放基准。
- 动画效果：支持漂移、呼吸、漩涡、波浪、浮动等动态纹理动画，以及激活态的涟漪、脉冲和扫过效果。
- 渐变背景：支持多色标线性渐变，也支持带噪声流动效果的动态渐变。
- 图层系统：支持多个纹理层和效果层，包含可见性开关、重命名、删除、拖拽排序和多种混合模式。
- 效果层：支持涂抹扭曲、流体扭曲、波纹、像素颗粒、轮廓线和绘制遮罩；其中轮廓线支持 `Luma / Inverse luma / Alpha` 三种输入模式、抗锯齿 WebGL 渲染、可编辑线条渐变色标与相位动画，形变类效果支持统一变换参数组。
- 预设管理：支持保存、加载、重命名、删除和重置预设。
- 图片导出：将当前画布合成结果导出为 PNG，导出分辨率使用配置的画布尺寸。

## 数据保存

项目内置预设文件位于：

```text
data/texture-presets.json
```

在开发环境中，Vite 中间件会通过 `/__texture/presets` 接口读写这个 JSON 文件，因此保存、重命名或删除预设会反映到本地文件。

在生产构建或静态部署环境中，浏览器无法直接写入仓库中的 JSON 文件。此时预设会保存到浏览器 `localStorage`，不会回写到 `data/texture-presets.json`。

当前编辑状态也会自动保存在浏览器 `localStorage` 中，用于刷新页面后恢复最近一次编辑内容。

## 使用注意

- 浏览器需要支持 Canvas 和 WebGL；如果 WebGL 不可用，部分高性能渲染或效果可能无法正常工作。
- 较大的画布尺寸、复杂点阵、动态渐变和多层效果会增加渲染开销，可能造成预览卡顿。
- 页面中的预览会按可用空间缩放显示，导出图片仍使用设置的完整画布尺寸。
- 鼠标交互、效果绘制和画笔操作主要作用于当前选中的图层或效果层。
- 生产环境中的预设保存依赖当前浏览器，同一链接在不同浏览器或设备上不会自动同步。
- 目前界面文案以中文为主。

## 优点

- 无需后端服务即可完成纹理编辑、预览和导出。
- 参数覆盖范围较广，适合快速试验多种点阵、渐变、动画和叠加效果。
- 支持图层和混合模式，可以组合出更复杂的视觉结果。
- 开发环境可直接维护本地预设文件，便于沉淀常用方案。
- 导出结果按画布尺寸生成，适合用于静态背景、视觉物料或进一步设计加工。

## 局限

- 没有账号系统、云端存储或跨设备同步能力。
- 静态部署后，预设修改只保存在浏览器本地，不会更新仓库中的预设 JSON。
- 高分辨率画布和复杂效果依赖浏览器性能，移动端或低性能设备体验可能不稳定。
- 部分底层参数虽然存在于渲染配置中，但尚未提供完整的界面入口。
- 当前导出格式为 PNG，不包含动画导出或工程文件导出。
